# Images des cartes (optionnel)

Le jeu affiche déjà une illustration stylée pour chaque carte (icône, couleurs par type, effets).

Pour utiliser vos propres images PNG à la place :

1. Placez les fichiers dans ce dossier `assets/`
2. Respectez les noms exacts (ex. `give2.png`, `diable.png`, `pickpocket.png`)
3. Format recommandé : PNG, ratio 2:3 (ex. 400×600 px)

Si le PNG est absent ou invalide, l'illustration intégrée s'affiche automatiquement.
