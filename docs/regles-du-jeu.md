# Règles du jeu

[← Accueil documentation](README.md) · [Liste des cartes](liste-des-cartes.md)

## Principe

Diable Noir est un jeu de défausse multijoueur. Chaque joueur reçoit des cartes en main. À son tour, il en joue une. Le but est de **vider sa main** avant les autres.

Quand la **pioche est vide** et qu'il ne reste qu'un joueur avec des cartes, si cette dernière carte est le **Diable Noir** 😈, ce joueur a **perdu** et boit **cul sec** (ou l'équivalent de votre choix).

## Mise en place

1. **2 joueurs minimum** (pas de maximum fixe ; choisissez une des **5 salles** en ligne).
2. Chaque joueur choisit un **pseudo** unique.
3. Le **premier arrivé** (👑 hôte) lance la partie avec **Démarrer**.
4. Les cartes sont mélangées ; chaque joueur reçoit une main de départ.

## Déroulement d'un tour

1. C'est au tour du joueur indiqué au centre de l'écran (**25 secondes** max).
2. S'il le souhaite, il **sélectionne une cible** sur le cercle (obligatoire pour certaines cartes).
3. Il **joue une carte** de sa main en cliquant dessus.
4. L'effet se résout (gorgées, pioche, vol, etc.).
5. Sauf exception, il **pioche 1 carte** et le tour passe au joueur suivant (selon le sens du jeu).

### Cartes non jouables

- **Diable Noir** : impossible à jouer ou défausser volontairement.
- **Malédiction** : reste en main ; vous buvez **1 🍺** au début de **chaque** tour tant qu'elle y est.

## Choisir une cible

Les cartes à cible affichent une bannière **« Choisis une cible »**.

- Les joueurs **valides** sont surlignés en **cyan**.
- Les joueurs **invalides** (ex. main vide pour un vol) sont **grisés**.
- Les cartes nécessitant une cible **pulsent en jaune** tant qu'aucune cible n'est choisie.

## Contres et défenses

Quand un joueur vous cible avec une attaque (gorgées, skip…), vous pouvez répondre **avant** de subir l'effet :

| Carte | Effet |
|-------|--------|
| **Protection** | Annule les gorgées |
| **Miroir** | Renvoie l'attaque à l'attaquant |
| **Retour de Flamme** | Renvoie le malus à l'attaquant |

Vous avez **25 secondes** pour choisir un contre dans votre main ou cliquer **Passer**.

### Défenses passives (jouées à l'avance)

| Carte | Effet |
|-------|--------|
| **Bouclier** | Absorbe automatiquement la prochaine attaque ciblée |
| **Miroir** (mode passif) | Renvoie le prochain malus reçu |
| **Retour de Flamme** (mode passif) | Idem |
| **Protection** (buff) | Protège contre la prochaine gorgée jusqu'au prochain tour de la cible |
| **Alliance** | Bloque les effets ciblés entre les deux alliés |

## Actions spéciales bloquantes

Certaines cartes interrompent le flux normal jusqu'à résolution :

- **Contre** en attente (réponse de la cible)
- **Pickpocket** (le joueur choisit quelle carte voler)
- **Tribunal** (tous les joueurs votent pour qui boit 4 🍺)

Timer : **25 secondes** ; sinon choix aléatoire ou effet subi.

## Tribunal

1. Le joueur joue **Tribunal**.
2. **Chaque joueur** clique sur un adversaire pour voter.
3. Le joueur avec le **plus de votes** boit **4 🍺** (égalité = tirage au sort).
4. Le tour reprend normalement.

## Fin de partie

La partie se termine quand :

- La **pioche est vide**, et
- **Un seul joueur** a encore des cartes, et
- Sa dernière carte est le **Diable Noir**.

→ Ce joueur **perd** ; les autres gagnent. Un **classement des gorgées** s'affiche.

## Interface utile

| Élément | Rôle |
|---------|------|
| **?** | Codex — toutes les cartes |
| **🔊** | Activer / couper les sons |
| **⏭ Passer** | Anti-bug : passe le tour (joueur actif uniquement) |
| **↻ Recommencer** | Hôte seulement — remet la salle à zéro |
| **Appui long** sur une carte | Voir la description |

## Bonnes pratiques

- Jouez **responsablement** (eau, pauses, respect des limites de chacun).
- Utilisez le **même pseudo** si vous vous déconnectez en cours de partie.
- L'hôte peut **Recommencer** si la partie est bloquée.
